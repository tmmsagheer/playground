# 🎡 Playground

Welcome to my personal repository of scripts, helper utilities, and configuration files! This is a public space for standalone tools, automation snippets, and code experiments. 

I frequently share individual files from this repository in my **LinkedIn posts** to discuss workflows, automation tips, and engineering solutions.

## 📁 Repository Structure

The codebase is organized by language, platform, or utility type to make it easy to browse:

*   `/skill` – Cadence SKILL and SKILL++ scripts for EDA design automation.
*   `/scripts` – General automation scripts (Python, Bash, PowerShell, etc.).
*   `/utils` – Helper functions, configurations, and small utility modules.

## 🚀 How to Use

Feel free to browse the folders, download individual files, or clone the entire repository for your own use. 

### Cloning the Repo
```bash
https://github.com/tmmsagheer/playground.git
```

### Grabbing a Single File
If you arrived here from one of my LinkedIn posts and want a single script:
1. Navigate to the file in the folder structure above.
2. Click the **Raw** button in the top right of the file view.
3. Right-click and choose **Save As...** or copy the contents directly.
